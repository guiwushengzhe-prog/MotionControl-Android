# 历史电脑面板

这里是早期 MotionBridge 服务的网页面板，保留作历史参考。当前 PC 界面在 [MotionControl](https://github.com/guiwushengzhe-prog/MotionControl) 仓库的 `web/`，由当前 `server.py` 管理面 `127.0.0.1:8766` 提供。

当前 Android 网页在本仓 `mobile/`，由 Capacitor 打包，并通过设备面 `/ws/input` 连接配套 PC。本目录不是当前手机或 PC 界面的正式入口，未搬动或删除。参见[仓库 README](../README.md)、[优化进度](../mobile/docs/optimization-progress.md)和[历史服务说明](../motionbridge/README.md)。
