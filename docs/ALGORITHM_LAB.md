# 动作与手势算法测试

## 使用

1. 启动 `MotionBridge-0.3.0-lab-mvp.exe`，连接摄像头手机。
2. 在电脑端选择玩家档案，点击“加入 / 重新锁定”，等状态显示“已锁定”。
3. 点击右上角“算法测试”。
4. 选择测试项目、玩家槽位、候选配置和次数，点击“开始真人测试”。
5. 按倒计时完成静止、握拳、捏合、握拳后立即捏合、下蹲或跳跃。
6. 测试结束后查看当前/候选参数的成功、漏识别、误触、重复触发、平均延迟、P95（95%事件延迟）、时间线和混淆矩阵。
7. 点击错误时间线可查看前后约 750ms 的原始信号和关键点；同一会话可再次重放比较，也可重命名、删除或导出 JSON/CSV。

测试期间 `Shadow Mode`（影子模式）会在输出路由层强制释放并锁住键盘、虚拟手柄与 DSU（模拟器体感协议）。测试结束后游戏输出保持关闭，如需继续玩游戏请手动点击“启用游戏输出”。

## 数据目录

- 源码运行：`F:\switch\data\algorithm-tests\sessions`
- 打包 EXE：`%LOCALAPPDATA%\MotionBridge\data\algorithm-tests\sessions`
- 导出文件：对应数据目录上一级的 `exports`

默认最多保留 30 个会话或 500MB，超过上限会优先清理最旧会话。玩家档案、历史校准和游戏映射不在该目录内，不参与清理。

MVP（最小可用版本）只保存真实人体/手部关键点、时间戳、原始动作信号和识别事件，不保存原始视频。会话格式已预留视频片段、PCM16（16位脉冲编码音频）、SensorFrame（传感器帧）和多人轨迹字段。
