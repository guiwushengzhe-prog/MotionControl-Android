# MotionBridge 项目长期决策

本文件用于追加已经确认的产品级硬规则。新决策只能续写，不覆盖既有内容。

## 2026-08-13：发布物必须可在独立设备上使用

- MotionBridge 是通用软件，不是针对当前荣耀手机或当前开发电脑制作的专用方案。
- 禁止硬编码手机品牌、型号、Camera ID（相机编号）、焦距、分辨率、传感器方向、局域网 IP、本机绝对路径、当前用户目录或当前设备缓存。
- 当前荣耀 ELI_AN00 仅作为一台实机验收样机；其测试通过不能表述为全安卓兼容，也不能成为代码中特判该型号的理由。
- 同一 APK（安卓安装包）安装到一台清空数据或从未安装过的独立安卓设备后，必须能自行探测镜头和 Camera2（安卓原生相机接口）能力，验证真实开镜、捕获会话和收帧，再选择分辨率、方向和回退路径。
- 同一电脑便携包复制到一台独立 Windows 电脑后，必须不依赖 `F:\switch`、`F:\MotionControl`、开发环境、当前用户缓存或预先写死的网络地址。
- 设备能力缓存只能用于加快通用探测，不能代替首次探测；缓存键可包含设备指纹、系统版本、应用版本和镜头标识，但不得触发品牌或型号专用逻辑。
- 玩家校准仍然保留。它是面向所有用户的通用档案功能，应支持不同玩家、多次和跨天记录；不得把当前用户的身体数据或校准结果打进发布包。
